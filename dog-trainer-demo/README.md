# 멍톡 🐩 — 강아지 훈련 음성 상담 데모

견주가 **말로** 질문하면 → OpenAI 음성인식으로 받아쓰고 → 블로그·유튜브·논문을 웹 검색해 답변하고 →
그 답변의 **신뢰도 / 정확성 / 빠르기**를 자동 분석해서 보여주는 데모 웹사이트.

## 실행

```bash
cd dog-trainer-demo
cp .env.example .env      # Windows: copy .env.example .env
# .env 파일을 열어 OPENAI_API_KEY 값을 본인 키로 교체
node server.js
```

브라우저에서 http://localhost:3000 접속.

npm 설치 불필요 — Node 18 이상 내장 기능만 사용합니다.

## 휴대폰에서 열기 (마이크 쓰려면 필수)

브라우저는 **HTTPS 또는 localhost**에서만 마이크(`getUserMedia`)를 허용합니다.
`http://192.168.x.x:3000`으로 들어가면 권한 요청 자체가 뜨지 않습니다 (주소창에 마이크 아이콘도 안 생김).

자체 서명 인증서를 한 번 만들어 두면 HTTPS로 열 수 있습니다:

```bash
node make-cert.js     # certs/key.pem, certs/cert.pem 생성 (이 PC의 랜 IP를 SAN에 자동 포함)
node server.js        # 인증서가 있으면 HTTPS(3443)를 자동으로 함께 띄움
```

휴대폰에서 `https://<랜IP>:3443` 접속 → 인증서 경고 화면에서 **[고급] → [계속]** → 마이크 권한 팝업이 정상적으로 뜹니다.

인증서 없이 HTTP로 접속하면 화면에 그 이유와 HTTPS 주소가 안내되고, **직접 입력**으로는 계속 사용할 수 있습니다.
휴대폰이 연결 자체를 못 하면 PC 방화벽에서 3443 포트(node.exe)를 허용해 주세요.

## 마이크 사용법

버튼을 **한 번 눌러 시작**, 다 말하고 **한 번 더 눌러 종료**.
누르고 있을 필요 없습니다. (60초가 지나면 자동 종료)

## 가상 프로필

`public/app.js` 상단 `PROFILE` 객체에서 수정합니다.

```js
const PROFILE = { name: "코코", breed: "토이푸들", sex: "수컷", age: 4, weight: "5.2kg", notes: "..." };
```

## 파이프라인

| 단계 | 처리 | 엔드포인트 |
|---|---|---|
| 1 | 브라우저 녹음(MediaRecorder) → base64 | — |
| 2 | 음성 → 텍스트 (`gpt-4o-transcribe`) | `POST /api/stt` |
| 3 | 웹 검색 기반 답변 + 출처 수집 (Responses API `web_search`) | `POST /api/ask` |
| 4 | 답변 품질 심사 (LLM 심판, JSON 출력) | `POST /api/eval` |

## 분석 리포트 계산 방식

- **신뢰도** — LLM 심판이 채점. 참고 소스의 권위·다양성·최신성 기준.
  논문/수의기관 자료가 섞이면 가점, 개인 블로그·영상만이면 감점, 소스가 없으면 40점 이하.
- **정확성** — LLM 심판이 채점. 현대 반려견 행동학(긍정강화 중심) 합의와의 일치도.
  지배이론·체벌 권장·과잉 일반화가 있으면 큰 감점. 프로필 반영 여부 포함.
  핵심 주장 2~4개를 뽑아 `근거 충분 / 부분 근거 / 근거 부족`으로 개별 판정.
- **빠르기** — 실제 측정값(음성인식 + 검색·생성 + 평가 소요 시간).
  4초 이하 100점, 22초 이상 25점 사이 선형 환산. (`speedScore()` in `public/app.js`)

소스 종류(논문 / 영상 / 블로그 / 기관·전문 / 웹)는 인용 URL의 도메인으로 자동 분류합니다
(`classify()` in `server.js`).

## 환경 변수

| 변수 | 기본값 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | (필수) | OpenAI API 키 |
| `OPENAI_MODEL` | `gpt-4o` | 답변·평가 모델 |
| `OPENAI_STT_MODEL` | `gpt-4o-transcribe` | 음성인식 모델 (`whisper-1`도 가능) |
| `PORT` | `3000` | 서버 포트 |

## 참고

- 웹 검색 도구 이름은 계정/모델에 따라 `web_search` 또는 `web_search_preview`입니다.
  서버가 순서대로 시도하고, 둘 다 안 되면 검색 없이 답변한 뒤 답변에 그 사실을 표시합니다.
- API 키는 서버에서만 사용하며 브라우저로 내려가지 않습니다.
- 데모용 프로토타입입니다. 의학적 진단을 대체하지 않습니다.
