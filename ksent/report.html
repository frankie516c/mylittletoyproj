NSMC로 학습된 공개 영화리뷰 감성분류 모델 3종을 로컬에 세팅하고, 직접 작성한 202개 행동 테스트와 NSMC held-out 5,000건으로 검증했다. 결론은 정확도표에 없다 — 반어법에서 세 모델 모두 “무조건 부정” 베이스라인보다 못했다.

한 줄 결론

부정문·대조문은 진짜로 학습돼 있다. 반어법은 전혀 학습돼 있지 않고, 모델은 그 사실을 모른다.

부정 처리는 TF-IDF 대비 +29%p로 트랜스포머가 실제로 버는 구간이다. 반면 반어법은 정확도가 낮은 정도가 아니라 다수클래스보다 낮고, 틀릴 때 확신도가 더 높다. 확신도 임계값으로 걸러낼 수 없다는 뜻이다.

발견

심각도 순. 번호는 우선순위이지 실행 순서가 아니다.

F01치명

반어법에서 세 모델 모두 다수클래스 베이스라인보다 못한다

반어 26케이스(부정 20 / 반어적 칭찬 6)에서 mbert .54, koelectra .50, kcelectra .35. “무조건 부정”을 찍으면 .77이다. 표면 어휘를 그대로 따라가며, 문장의 후반부가 앞부분을 뒤집는 구조를 읽지 못한다.

  • “명작이네요 명작. 화장실 갈 타이밍 잡기 딱 좋은.” 정답 부정 · mbert 0.96 / koelectra 0.98 / kcelectra 0.97
  • “팝콘이 참 맛있었습니다.” 정답 부정(영화 얘기를 안 함) · 0.79 / 0.95 / 0.96
  • “돈 아깝네요. 티켓값이 이 퀄리티에 비해 너무 쌉니다.” 정답 긍정(반어적 칭찬) · 0.00 / 0.00 / 0.05
  • “최악입니다. 이걸 보고 나니 다른 영화가 다 시시해졌어요.” 정답 긍정 · 0.00 / 0.02 / 0.04
F02치명

틀릴 때 더 확신한다 — 확신도 필터링이 통하지 않는다

행동 테스트 오답 중 확신도 0.9 초과인 비율: koelectra 55%, kcelectra 56%, mbert 34%. 얕은 TF-IDF 베이스라인은 12%다. 즉 트랜스포머는 어려운 케이스에서 조용히 애매해지는 게 아니라 자신 있게 틀린다. “확신도 0.9 미만은 사람이 검수” 같은 운영 규칙으로 F01을 막을 수 없다.

다만 3종 평균 앙상블은 이 비율을 24%로 떨어뜨린다. 모델 간 불일치가 난이도 신호로 작동하기 때문이며, 실무에서 유일하게 값싼 완화책이다.

F03중대

P(pos)는 감성 “강도”가 아니다 — 별점 추정에 쓸 수 없다

부정 뒤집기는 완벽하지만(Δ≈−0.94) 강도 변화에는 아무 반응이 없다. 확률은 0.97~0.99에 포화된 이진 스위치다. 긍정 문장에 불만 절을 덧붙여도 확률이 내려가지 않는 점이 특히 위험하다.

  • “재미있었다” → “정말 너무 재미있었다” (기대: 상승) mbert +0.010 / koelectra +0.018 / kcelectra −0.000
  • “지루했다” → “너무너무 지루했다” (기대: 하락) mbert +0.000 / koelectra +0.003 / kcelectra +0.000
  • “괜찮은 영화였다” + “다만 결말이 많이 아쉬웠다” (기대: 하락) mbert +0.002 / koelectra −0.018 / kcelectra −0.012
  • “재미있었다” → “재미없었다” (기대: 하락) mbert −0.978 / koelectra −0.959 / kcelectra −0.937

강도 사다리에서도 같은 패턴이다. 긍정 사다리는 단조 증가하지만 두 번째 단계에서 이미 0.97에 닿아 이후가 평평하고, 부정 사다리는 전 모델 단조성 실패 — “별로였어요”에서 곧장 0.002로 떨어진 뒤 “인생 최악의 영화”까지 변화가 없다.

F04중대

무관한 문장을 앞뒤에 붙이면 mbert·kcelectra는 30%가 뒤집힌다

의견과 무관한 문맥(“어제 친구랑 같이 극장에서 봤습니다.” … “참고로 주차는 3시간 무료였습니다.”)만 덧붙였는데 라벨이 바뀐 비율이 mbert 30.2%, kcelectra 28.2%다. 실제 리뷰는 이런 잡담을 항상 포함하므로, 짧은 문장으로 만든 벤치마크 점수가 실사용 성능을 과대평가한다.

같은 조건에서 koelectra는 3.0%, 앙상블 4.0%, TF-IDF 2.0%로 견고하다. 이 항목이 모델 선택을 가르는 가장 큰 실무 기준이다.

F05중대

NSMC 정확도는 모델 품질을 거의 구분하지 못한다

char n-gram TF-IDF + 로지스틱회귀만으로 NSMC 전체 테스트셋 49,997건에서 0.8714가 나온다. mbert-nsmc(0.8724)와 사실상 동일하고 McNemar p=0.047로 겨우 유의하다. 즉 NSMC 점수 1~2%p 차이는 “어휘 통계 대비 이 모델이 무엇을 더 아는가”를 말해주지 않는다.

그 차이는 행동 테스트에서만 드러난다. 부정문 .67→.96, 대조문 .70→1.00, 적대적 어휘주입 .62→.88 — 트랜스포머가 실제로 버는 구간은 여기다.

F06중대

NSMC 골드 라벨 자체가 상당히 오염돼 있다

세 트랜스포머가 모두 골드와 반대로 예측한 139건(2.78%)을 전수 판정했다. 결과는 골드 라벨 오류 32건(23.0%), 판정 불가 80건(57.6%), 진짜 모델 실패 27건(19.4%).

  • “최고의 감동이지 아니하지 않을수 잇네” — 골드 부정 이중부정 긍정문. 라벨 오류
  • “너무재밋다^_^” — 골드 부정 라벨 오류
  • “평은 최대 한글 140자까지 가능합니다.” — 골드 부정 리뷰가 아니라 시스템 문구. 판정 불가
  • “ㅋㅋ” — 골드 부정 (3건) 극성 판정 자체가 불가능. 판정 불가

실질 모델 실패는 전체의 0.54%뿐이다. 뒤집어 말하면 NSMC의 실효 상한은 100%가 한참 아래이고, 공개 리더보드의 90% 초반 수치는 모델 한계가 아니라 데이터 한계에 가깝다. 이 데이터셋으로 소수점 경쟁을 하는 것은 의미가 없다.

F07양호

부정·이중부정·대조·전언 구분은 실제로 작동한다

koelectra 기준 부정문 .96, 이중부정 1.00, 대조문 1.00, 전언 vs 내 의견 .94. “평이 좋길래 봤는데 저한텐 별로였어요”처럼 남의 평가와 내 평가가 반대인 문장을 제대로 가른다. 얕은 베이스라인이 못 하는 일이고, 감성사전은 부정문에서 .33으로 무너진다.

단 mbert는 이중부정 .56으로 우연 수준이다. 같은 NSMC로 학습했더라도 백본에 따라 결과가 갈린다.

F08양호

개체명·장르 지름길 학습 흔적은 없다

같은 문장에서 배우 이름 12종(한국/외국, 성별 혼합)만 교체했을 때 P(pos) 변동 폭은 koelectra 0.005~0.007, mbert 0.002~0.039, kcelectra 0.002~0.033. 장르 12종 교체 시 트랜스포머는 0.006 이하다. 정확도는 세 템플릿 모두 1.00.

흥미롭게도 TF-IDF 베이스라인이 더 편향돼 있다 — 개체명 폭 0.111, 장르 폭 0.094. 특정 이름·장르 문자열이 학습셋에서 특정 라벨과 공기했기 때문이며, 트랜스포머는 이를 상당히 씻어냈다.

F09주의

보정은 대체로 양호하나 kcelectra는 특정 구간에서 크게 어긋난다

ECE는 koelectra 0.010으로 우수, mbert 0.031, kcelectra 0.034. 그러나 MCE(구간 최대 오차)는 kcelectra가 0.215로 튄다 — 확신도 0.80~0.85 구간의 실제 정확도가 0.613에 불과하다. 온도 스케일링(T*=1.14)으로도 ECE가 0.0340→0.0342로 개선되지 않는다. 단일 온도로 고칠 수 있는 종류의 오차가 아니다.

mbert(T*=1.34)와 앙상블(T*=0.76)은 온도 스케일링으로 ECE가 절반 이하로 떨어지므로, 확률값을 쓸 계획이라면 보정을 반드시 붙여야 한다.

검증 방법과 한계

이 검증이 방어하는 것

  • 라벨 극성 실측. 허브의 id2label을 믿지 않고 명백한 긍/부정 프로브로 방향을 직접 확인했다. 세 모델 모두 index 1 = 긍정, 분리도 0.94~0.99. kcelectra는 LABEL_0/LABEL_1로만 표기돼 있어 이 단계 없이는 극성을 뒤집어 쓸 위험이 있었다.
  • 유출 검사. 수제 문장 210개를 NSMC train 150k / test 50k와 대조했다. 정확 일치 15건은 전부 “재미있었다”류 짧은 상용구(DIR·사다리·패러프레이즈 세트)였고, 결론이 걸린 MFT 난이도 세트는 정확 일치 0건이다.
  • 다수클래스 베이스라인 병기. 반어 세트가 부정 라벨로 치우치면 “무조건 부정” 모델이 만점을 받으므로, 반어적 칭찬 6케이스를 넣어 .77로 낮췄고 모든 셀에 이 값을 함께 표기했다.
  • 얕은 상한선. NSMC train 150k로 학습한 char n-gram TF-IDF를 같이 돌려, 어휘 통계만으로 도달 가능한 지점을 명시했다.

믿으면 안 되는 것

  • 골드 라벨 주석자가 1명이다. 202케이스의 정답과 139건 오분류 판정 모두 2차 검수를 받지 않았다. 특히 판정 불가(U) 80건의 배분에 주석자 편향이 들어갈 수 있다. 원자료는 results/cases.csv와 adjudication.py에 남겨 재판정이 가능하다.
  • 소분류 표본이 작다. n=6~26이라 Wilson CI가 ±0.2에 이른다. 확실한 결론은 반어(n=26, CI 상한도 다수클래스 미만)와 부정(n=24) 정도이고, 가정법(n=6)·장문(n=3)은 방향 참고용이다.
  • NSMC는 5,000건 부분표본이다. 전체 50,000건이 아니다(CPU 추론 비용). TF-IDF만 전체 테스트셋을 돌렸고 0.8714였다.
  • koelectra-gen은 도메인이 다르다. 쇼핑 리뷰 기반 범용 감성 모델이라 NSMC 기준으로는 out-of-domain인데도 1등이다. 영화 전용 학습이 반드시 유리하지 않다는 뜻이지만, 비교의 공정성 측면에서는 감안이 필요하다.
  • 오타 변형은 드물게 의미를 바꾼다. 받침 탈락이 “연기”를 “여기”로 만드는 식이다. 그래서 의미 보존군과 오타군을 표에서 분리했다.

그래서 쓸 수 있나

쓸 수 있다 — 단, 반어가 드문 데이터에 한해서, 라벨만.

일반 리뷰 대량 집계처럼 반어 비중이 낮은 용도라면 Copycats/koelectra-base-v3-generalized-sentiment-analysis가 명확한 1순위다. NSMC .924, 행동 테스트 .90, 문맥 패딩 flip 3.0%로 세 축 모두에서 앞선다.

확률값을 점수로 쓰지 말 것. F03에서 보듯 P(pos)에는 강도 정보가 없다. 별점 예측이 필요하면 회귀로 다시 학습해야 한다.

확신도 기반 사람 검수는 반어를 못 잡는다. 대신 3종 앙상블의 불일치를 검수 큐 신호로 쓰면 고확신 오답이 55%→24%로 떨어진다. 비용은 추론 3배.
